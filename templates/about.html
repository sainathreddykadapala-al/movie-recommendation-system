College Final Year Academic Project

Movie Recommendation System

Using Clustering and Similarity-Based Machine Learning Techniques on the TMDB 5000 Benchmark

Problem Statement

With thousands of films published across modern global streaming platforms, users face severe choice overload. Finding movies that genuinely match specific narrative preferences, genre mixtures, and thematic undertones is challenging through manual keyword queries or simple popularity rankings alone.

Proposed Solution

A content-based and clustering-guided Machine Learning recommendation pipeline that ingests comprehensive textual metadata (plot overview, tagline, genres, keywords, directors, and actors). The system uses TF-IDF feature extraction, partitions movies into semantic clusters via K-Means, and ranks target films using high-dimensional Cosine Similarity.

Machine Learning End-to-End System Workflow

1
Dataset Collection

Ingestion of TMDB 5,000 movies and credits datasets containing comprehensive metadata for 4,803 real films.

2
Data Preprocessing

Inner join on movie ID, JSON string parsing for genres/keywords/cast, director isolation from crew, null imputation, and duplicate removal.

3
Feature Engineering

Normalization, space collapsing for entity names (e.g., 'Christopher Nolan' → 'christophernolan'), and composition of weighted 'tags'.

4
TF-IDF Vectorization

Transformation of combined tags into 5,000-dimensional sparse numerical feature vectors using scikit-learn TfidfVectorizer.

5
K-Means Clustering

Unsupervised grouping of movies into 12 semantic clusters to narrow candidate space and isolate topical themes.

6
Cosine Similarity Calculation

Computation of angular proximity between the query movie vector and candidates, excluding the query movie itself.

7
Recommendation Generation

Extraction of the top 10 ranked candidates with calculated similarity score percentage and dynamic shared metadata explanations.

8
Model Persistence & Delivery

Serialized via Joblib for zero-delay inference through Flask RESTful routes and a responsive Three.js UI.

Mathematical Formulations

1. TF-IDF Weighting

Balances term frequency with inverse document frequency across the corpus:

TF-IDF(t, d, D) = TF(t, d) × log(N / DF(t))

Penalizes omnipresent words while emphasizing characteristic director and genre tokens.

2. K-Means Objective Function

Minimizes within-cluster sum of squared Euclidean distances (Inertia):

J = ∑ ∑ || x_i - μ_j ||²

Clusters movies into coherent thematic domains (e.g. Action/Sci-Fi vs Drama vs Animation).

3. Cosine Similarity Metric

Measures cosine of angle θ between two non-zero vectors A and B:

cos(θ) = (A • B) / (||A|| × ||B||)

Invariant to document length, focusing purely on directional orientation in vector space.
